FAQ

Questions, answered

Can I reschedule an appointment?

Yes. Use My Appointments, find the booking with your phone number, and choose Reschedule.

What happens if I need urgent care?

Call the clinic directly. The emergency service is intended for urgent cases and the demo booking form also supports emergency-care appointments.

Can I book for cats and birds?

Yes. Select Dog, Cat, Bird or Other in the pet type field.

Is this connected to a real database?

This version uses localStorage so it works without a server. It is structured so a Node/Express + MongoDB API can replace the storage layer later.
